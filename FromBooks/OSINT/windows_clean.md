# Windows 11 Factory Reset Guide

## Step 1: Backup Your Data
- Connect an external USB drive.
- Copy important files from:
  - Desktop
  - Downloads
  - Documents
  - Any other folders with personal or configuration files
- Double-check that all necessary files are saved.

## Step 2: Access Reset Options
- Search for **"Reset this PC"** in the Start menu.
- Select the option to reset.
- Choose **"Remove everything"** for a clean installation.
- Follow the prompts until the reset begins.

## Step 3: Alternative for Older Systems
- If no restore partition is available:
  - Use original installation media (USB/DVD).
  - Or obtain a restore CD from the manufacturer.
- Boot from installation media and follow setup instructions.

## Step 4: Account Setup
- Avoid creating a Microsoft account if you prefer local login.
- Provide only minimal details (username and password).
- Disconnect from the internet during setup to prevent online account requirements.

## Step 5: After Reset
- You will have a fresh Windows installation.
- Reconnect to the internet after setup.
- Restore backed-up files from the external drive.
